R21 — 방문객·대화·아이콘·검격 수정

- 공방 방문객을 동시에 한 명으로 제한.
- 실제 입장 경로 이동 → 대화 대기 → 퇴장 경로 이동 → 다음 방문.
- 의뢰는 초상화 대화로 한 건만 제안. 수락/거절 후 인사하고 퇴장.
- 거래 방문과 기존 이야기 대화도 기존 내용을 사용하며 종료 후 퇴장.
- 방문 간격과 방문 기록 저장. 미수락 의뢰를 자동 수락하지 않음.
- 범용 기호로 바꿨던 기존 아이템 아이콘 복구. 신규 품목만 기존 코드 아이콘으로 보완.
- 기존 캐릭터 원화·표정·대화 데이터를 그대로 사용.
- 검격을 반경 2.0, 마무리 2.2의 전방 120도로 제한.
- 근거리 예외로 뒤쪽까지 맞던 판정 제거. 자동 조준도 전방 적만 선택.
- 검격 그림 방향과 실제 판정 방향 일치. 기존 검격 피해 배율 복원.
- 검 인챈트 발동도 전방으로 제한.

확인: 방문 상태 전환, 한 번만 수락, 퇴장/대기 간격,
전후방 타격 조건, 아이콘 연결, 전체 모듈 문법.
실제 브라우저 플레이 완주/태블릿 검증은 하지 않았음.
기존 마을 장소 전제 사건의 전체 이식은 여전히 미완료.
