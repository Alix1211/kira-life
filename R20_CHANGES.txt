공방주 키라의 라이프 R20 — 2026-11-26

수정 기준: 마을 대신 공방, 세계지도 직접 이동, 의뢰인 방문,
지역 자유 진입, 넓은 검격, 대상에 따른 최소 조작.

반영
- 마을 생성·순회 시작을 제거. 12×10 공방에서 시작.
- 침대·의자·제작대·창고·출입문·방문객을 서로 떨어뜨려 배치.
- 상시 메뉴 하나. 대상에 따라 잠자기/휴식/제작/창고/밖으로/대화.
- 채집 대상 앞에는 줍기. 획득은 1.05초짜리 짧은 글씨.
- 별도 지도·가방·의뢰·달리기·카메라·줍기·수액 버튼 숨김.
- 던전은 공격/회피. 재료·전리품을 주울 때는 상호작용으로 전환.
- 문에서 세계지도. 숲·농지·강·호수·광산·던전 각 층 직접 선택.
- 지역의 메인 진행/이전 층 클리어 진입 제한 제거.
- 의뢰인·상인이 공방을 방문. 의뢰와 이야기를 별도로 선택.
- 수락한 주문은 낮은 제작 등급/품질부터 목록에 표시. 공방에서 납품.
- 주문 수락 제한을 12건으로 통일하고 표시와 처리의 제한값을 맞춤.
- 공격 사거리 약 3.3~4.2, 넓은 각도, 두 명 타격 제한 제거.
- 누르고 있으면 연속 공격. 세 번째 베기에서 검 인챈트 마법 발동.
- 적 탐지 범위 30, 우회 추격. 적 무리 확대, 동시 공격 2→5.
- 기존 저장의 마을/상점 실내 위치를 공방으로 옮겨 이어받음.
- 적 무리의 확장된 저장 키를 허용. 기존 12칸 던전 저장 형식 유지.
- 제작 해금이 해당 제작/연금술 숙련을 보도록 수정.
- 캐릭터 원화와 기존 에셋 파일은 변경하지 않음.

확인 범위
- 게임 모듈과 추가 소스의 문법 확인.
- 상황별 버튼 표시 8가지 확인, 에셋 참조 276건의 파일 존재 확인.
- 전체 플레이, 전투 밸런스, 실제 태블릿 조작 검증은 진행하지 않음.
- 기존 개인 시나리오/비공개 사건 데이터는 유지. 마을의 특정 장소를
  전제로 한 사건 전체의 공방 방문 전환과 완주 확인은 미완료.

실행
이 버전은 assets 폴더를 함께 사용하는 웹 배포본이다.
파일 주소로 index.html만 여는 대신 GitHub Pages 또는 로컬 서버 사용.
로컬: 이 폴더에서 node serve.cjs 실행 후 http://127.0.0.1:8080 접속.
r20-update.js 수정 후 node build-r20.cjs로 index.html에 반영.
