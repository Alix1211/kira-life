R22 — 편지함·방문 횟수·라벤더 UI

반영
- 일반 납품의뢰를 방문객에게서 편지함으로 이동.
- 공방 문 오른쪽에 편지함 설치. 가까이 가면 기존 행동 버튼에 편지함 표시.
- 하루 4통: 현재 제작 가능한 의뢰 2통, 한 등급 위 의뢰 2통.
- 제작 가능 여부는 배운 제조법과 실제 제작/연금술 숙련 기준.
- 당일 편지 내용과 수락 상태 저장. 새로 열어도 재추첨하지 않음.
- 이미 받은 의뢰의 중복 수락 차단.
- 최고 등급에서는 없는 다음 등급을 만들지 않고 현재 등급 의뢰로 구성.
- 방문으로 제안/보고하는 이야기·개인 퀘스트는 하루 1회.
- 상인 방문은 별도로 하루 1회. 일반 납품의뢰 방문 제거.
- 방문 시 하루 제한 기록을 즉시 저장. 기존 퀘스트 데이터는 유지.
- 사용자의 최종 지시에 따라 기존 납품 기한 유지.
- 라벤더 패널·텍스트 플레이트·버튼 이미지 적용.
- 메뉴·지도·편지·가방·의뢰·장비·상태·닫기 아이콘은 8칸 시트 한 장 사용.
- 기존 아이템 아이콘·캐릭터 원화·표정 보존. 기존 최소 버튼 구성 유지.

확인 범위
- 실제 카탈로그/주문 데이터로 숙련 0/15/35/55 단계의 2+2 배분 확인.
- 최고 등급 처리, 당일 고정, 수락 중복 방지, 저장 복구 확인.
- 방문 하루 제한과 다음 날 초기화 확인. 모듈 문법 확인.
- 생성 이미지 세 장의 색·구성·투명 배경과 시트 배치 시각 확인.
- 게임 전체 플레이, 태블릿 조작과 기존 사건 전체 이식 검증은 미완료.

보류: 세계지도에서 지역만 표시하고 심층은 거쳐 이동하거나 방문 이력으로
빠른 이동하는 구조. 사용자가 이번 작업 종료 후 다시 논의하도록 지시함.
이번 R22에서는 이동 구조를 추가 변경하지 않음.
